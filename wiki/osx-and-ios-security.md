OSX and iOS related security tools

## What it is
A short curated list of macOS and iOS security tools. It has a macOS Security section and an iOS Security section, the latter covering app testing, iOS security tools and jailbreaks. The README states the work is under Creative Commons Attribution-ShareAlike 4.0.

## Who it is for
Mobile and Apple-platform security testers who want a compact list of tooling.

## Caveats
- Jailbreak and tooling compatibility can change with each iOS release; verify before relying on a tool.
- Test only devices and apps you own or are authorized to assess.
- For the Android counterpart see [Android Security](android-security.md).
