List of resources related to Industrial Control System (ICS) security

## What it is
The README describes a list of resources on ICS security. It uses tables for entries and sections cover tools (for example a PLC static-analysis tool), distributions, honeypots, data, frameworks, feeds and news, and conferences with their materials.

## Who it is for
ICS/OT security researchers and defenders looking for tools, datasets and conference material.

## Caveats
- Test ICS and OT systems only with explicit authorization; active probing can disrupt physical processes.
- Some linked tools are hosted outside GitHub, which raises dead-link risk.
- Overlaps with [Embedded and IoT Security](embedded-and-iot-security.md) on device-level topics.
