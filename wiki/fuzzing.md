List of fuzzing resources for learning Fuzzing and initial phases of Exploit Development like root cause analysis

## What it is
The README describes a list of fuzzing resources aimed at learning fuzzing and the early stages of exploit development such as root cause analysis. It covers books, free and paid courses, videos (including NYU Poly course videos and conference talks), tutorials and blogs, and tools by type: cloud, file format, network protocol and browser fuzzers.

## Who it is for
Learners entering vulnerability research and testers choosing a fuzzer for a target type.

## Caveats
- Fuzz only software and systems you own or are authorized to test.
- The default branch was last committed in 2023, so newer fuzzers and techniques are probably missing.
- Overlaps with [Linux Kernel Exploitation](linux-kernel-exploitation.md) for kernel fuzzing links.
