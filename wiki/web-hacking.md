List of web application security

## What it is
The README describes a list for people who want to learn web application security but lack a starting point. Sections: Books, Documentation, Tools, Cheat Sheets, Docker images for penetration testing, Vulnerabilities, Courses, Online Hacking Demonstration Sites, Labs, SSL, and Security Ruby on Rails.

## Who it is for
Beginners in web application security looking for books, labs and practice sites.

## Caveats
- Book links point to retailer pages, which may go stale.
- Demonstration and lab sites can go offline.
- Overlaps with [Web Security](web-security.md), which is organised by vulnerability class.
- Test only systems you are authorized to attack.
