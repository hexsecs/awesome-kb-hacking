Curated list of Web Security materials and resources

## What it is
A large curated list of web security reading and tools, organised mainly by vulnerability class. The README opens with digests and forums, then covers topics such as XSS, prototype pollution, SQL and command injection, XXE, CSRF, clickjacking, SSRF, cache poisoning, SAML, file upload, framework-specific notes (Rails, AngularJS, ReactJS), SSL/TLS, cloud (AWS, Azure) and more. It also advertises a Claude Code skill version of the list.

## Who it is for
Web testers looking for write-ups and references on a specific bug class.

## Caveats
- The list is big (the README is about 80 KB), so entries vary in age and some links will be dead.
- The techniques are offensive; test only systems you are authorized to assess.
- Heavy overlap with [Web Hacking](web-hacking.md) and [PayloadsAllTheThings](payloadsallthethings.md).
- This page does not evaluate the optional AI skill install described in the README.
