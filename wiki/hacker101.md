A free class for web security by HackerOne

## What it is
The README describes the repository as the source for Hacker101, which it calls a free class for web security. The README itself only covers building the site locally (Ruby, bundler, Jekyll) and contributing via issues and pull requests; it does not describe the course content.

## Who it is for
Programmers curious about bug bounties and security professionals wanting web security training.

## Caveats
- The README is short and says little about course content; check the site for current material.
- The list describes the class as made by HackerOne; the README does not say how the material is scoped.
- Apply what you learn only to targets you are authorized to test, such as in-scope bounty programs.
