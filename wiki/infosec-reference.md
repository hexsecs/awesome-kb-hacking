Information Security Reference That Doesn't Suck

## What it is
The README calls this an information security reference and states its goal as a free resource and a pointer list of techniques, tools and tactics, comparing it to yellow pages for things you know exist. The index spans many topics, including ATT&CK, Active Directory, cloud, courses, cryptography, CTFs, defense, exploit development, forensics and fuzzing, with a separate HTML version.

## Who it is for
Learners and practitioners who want a wide set of topic pointers to jump into a niche.

## Caveats
- The README opens with political commentary; the resource index follows below it.
- The README says it is not meant to condone illegal or malicious activity.
- Topic pages are link collections and some links will have rotted.
