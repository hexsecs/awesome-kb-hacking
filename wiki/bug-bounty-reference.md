List of bug bounty write-up that is categorized by the bug nature

## What it is
The README describes a list of bug bounty write-ups categorised by vulnerability type, inspired by the Awesome Bug Bounty list. Its contents include XSSI, XSS, brute force, SQL injection, XXE, RCE (with deserialization and ImageTragick), CSRF, IDOR, access-token theft, SSRF and file upload issues. The author explains the idea: look up write-ups for a bug class you have found but do not know how to exploit.

## Who it is for
Bug bounty hunters who already found a bug class and want worked public examples.

## Caveats
- Write-ups are third-party posts, so link rot is likely; the last commit is from 2024.
- Techniques apply only to programs and targets you are authorised to test.
- Related but different from [Bug Bounty](bug-bounty.md), which lists programs and authors.
