Cutting-edge open-source security tools (OST) for red teamers and threat hunters

## What it is
A collection of open-source tools for adversary simulation, which the README also pitches to threat hunters for improving detection. It is organised by attack phase: reconnaissance, initial access (brute force, payload development), delivery (phishing, watering hole), command and control (RATs, staging, log aggregation) and situational awareness (host and domain), with more phases beyond what we captured.

## Who it is for
Red teamers and blue teamers who want tools grouped by kill-chain stage.

## Caveats
- Contains offensive tooling that can be misused; use only in authorized engagements.
- Tool links decay as projects get renamed or removed.
- The upstream README is about 50 KB and our capture was truncated at 20 KB, so later phases were not reviewed.
- For a broader directory see [Pentest](pentest.md).
