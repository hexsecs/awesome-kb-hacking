List of amazingly awesome Open Source Intelligence (OSINT) tools and resources

## What it is
A very large curated list of open source intelligence tools and resources. The README says it targets cyber threat intelligence, threat hunting and OSINT work from beginner to advanced. Sections start with general search, Google dork tools, national, meta, privacy-focused, data-breach, speciality and dark web search engines, then continue through many further categories.

## Who it is for
OSINT practitioners, threat hunters and investigators who want a broad, categorised starting point.

## Caveats
- Very large (the upstream README is over 150 KB), so many entries are likely stale or dead; we reviewed only the first 20 KB.
- Data-breach search tools raise legal and privacy issues; use them lawfully and ethically.
- Overlaps with [Threat Intelligence](threat-intelligence.md) on threat-intelligence sources.
