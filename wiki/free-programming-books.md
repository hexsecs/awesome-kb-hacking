Free programming books for developers

## What it is
The README presents a large, multi-language index of free learning resources: books, cheat sheets, online courses, interactive resources, problem sets, podcasts and screencasts, and playgrounds. It has contribution guidelines, a search site and translations. It is a general programming list, not a security list.

## Who it is for
Anyone building programming fundamentals, including security learners who need coding background.

## Caveats
- Not security-specific; it is included in the source list as general background reading.
- The README displays a CC BY 4.0 license badge (self-described).
- Links to external books and courses rot over time, and availability or price can change.
