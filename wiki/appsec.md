Resources for learning about application security

## What it is
The README describes a curated list for learning application security. It mixes books, websites, blog posts and self-assessment quizzes, and Paragon Initiative Enterprises maintains it with community input. Entries carry a publication year and non-free books are flagged with an icon. It points beginners to an introductory article by the maintainers.

## Who it is for
Developers and newcomers to application security who want a reading and study list.

## Caveats
- Many listed items carry years between 2004 and 2018, so some advice on cryptography and tooling may be dated.
- Several listed books are marked as non-free.
- Only the first 20 KB of a roughly 34 KB README was reviewed.
- For a concrete API checklist see [API Security Checklist](api-security-checklist.md).
