List of tools for incident response

## What it is
The README describes a list of tools and resources for security incident response, aimed at analysts and DFIR teams. Its tool collection covers adversary emulation, all-in-one tools, books, communities, disk imaging, evidence collection, incident management, knowledge bases and Linux distributions. It uses a URL-check workflow to catch broken links.

## Who it is for
SOC analysts and DFIR teams building a response toolkit.

## Caveats
- Collection and imaging tools should be used under proper authority and chain-of-custody practice.
- Overlaps with [Forensics](forensics.md); this list also includes incident management resources.
- Link checking exists upstream, but individual tools may still be unmaintained.
