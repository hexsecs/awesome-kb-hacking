Suricata IDS/IPS and network security monitoring resources

## What it is
A curated list around Suricata, the free IDS/IPS and network security monitoring engine. Sections include input and output tools, operations and troubleshooting, libraries, dashboards, development tools, documentation, analysis tools, rule sets, rule management, plugins, systems using Suricata, training, simulation and data sets.

## Who it is for
Network defenders and SOC engineers running or tuning Suricata.

## Caveats
- Specific to one engine; for general detection content see [Detection Engineering](detection-engineering.md).
- Third-party plugins and rule sets vary in upkeep; check each project.
- Rule sets and simulation tools can generate noisy alerts, so test outside production.
