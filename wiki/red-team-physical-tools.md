Curated list of tools for physical security, red teaming, and tactical covert entry

## What it is
A personal, curated list of commercially available tools for physical security assessments and covert entry. Sections cover reconnaissance, lockpicking and entry, bypass tools, implants and drops, everyday carry, additional tools and suppliers, plus a total estimated cost. The author says these are items used on authorized engagements.

## Who it is for
Physical penetration testers and red teamers building a kit for authorized work.

## Caveats
- The README warns that use requires written authorization, that many items may count as burglary tools in some jurisdictions, and that the author is not liable.
- The README discloses affiliate links, and its prices are approximate as of February 2026.
- It reflects one practitioner's kit, so coverage is opinionated. For software tools, see [Red Teaming Toolkit](red-teaming-toolkit.md).
