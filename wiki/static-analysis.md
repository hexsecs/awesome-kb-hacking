List of static analysis tools, linters and code quality checkers for various programming languages

## What it is
The repository lists static analysis tools for programming languages, build tools and config files, with a focus on linters, formatters and code-quality checkers. The README says the official site analysis-tools.dev is built from it, and that edits belong in files under data/tools rather than the README. Symbols mark proprietary tools and ones the community does not recommend for new projects.

## Who it is for
Developers choosing linters and analyzers for a given language.

## Caveats
- Covers code quality in general, not only security scanners.
- Propose changes via the data/tools files, as the README asks.
- Very large list; only the first 20 KB of a roughly 195 KB README was reviewed.
- Includes proprietary tools, flagged in the README.
