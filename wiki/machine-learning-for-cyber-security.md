Curated list of tools and resources related to the use of machine learning for cyber security

## What it is
The README describes a curated list on using machine learning for cyber security. Its table of contents lists datasets, papers, books, talks, tutorials, courses and miscellaneous resources.

## Who it is for
Researchers and defenders exploring ML for detection tasks, and people looking for security datasets.

## Caveats
- This is ML applied to defense; for attacking or defending ML systems see [AI Security](ai-security.md).
- The default branch was last committed in April 2024, so recent work is likely missing.
- Datasets listed may have their own licenses or access terms.
