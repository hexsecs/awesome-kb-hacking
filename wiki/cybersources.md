A collection of all types of tools and resources for cybersecurity

## What it is
The README describes a central hub of tools, resources and learning material for cybersecurity professionals and learners. Section names include OSINT (username, email, phone and GEOINT lookups), Social Networks, Post Exploitation, Cryptography, Forensic, Malware Analysis, Privacy and Anonymity, Utility, AI Cybersecurity, Hardware Tools, Courses and Certifications.

## Who it is for
Anyone wanting a very broad starting directory across many security sub-fields.

## Caveats
- Extremely large (the README is about 306 KB); only the first 20 KB was reviewed.
- The README shows a corporate sponsor and a Discord community link.
- Includes people-search and OSINT lookups; use them lawfully and respect privacy.
- Its breadth overlaps several other pages; see [OSINT](osint.md) and [Infosec Reference](infosec-reference.md).
