Various public documents, whitepapers and articles about APT campaigns

## What it is
The README describes a repository of publicly available documents and notes about APT campaigns, sorted by year. The reviewed portion lists dated report titles for 2019 to 2023, mostly linked to files on an external file-sharing host. It also points to a separate data repository for automation and for submitting new reports.

## Who it is for
Threat-intelligence analysts and researchers who want a chronological index of vendor APT reporting.

## Caveats
- Links go to external file-sharing URLs, so dead-link risk is real.
- The README points to a separate data repository for automation and new report submissions; the latest entry in the captured part is December 2023.
- Reports can reference malware sample hashes; handle any samples as hostile.
- Only the first 20 KB of an 84 KB README was reviewed.
