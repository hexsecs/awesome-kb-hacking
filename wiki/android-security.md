Collection of Android security related resources

## What it is
The README describes a collection of Android security resources. It is organised as Tools (online analyzers, static analysis, app vulnerability scanners, dynamic analysis, reverse engineering), Academic/Research/Publications/Books, and Exploits/Vulnerabilities/Bugs. Some tool entries are labelled as not free.

## Who it is for
Mobile app testers and reverse engineers who want a starting map of Android analysis tooling and research.

## Caveats
- Several online analyzers are commercial or quota-limited, as the entries themselves note.
- Only the first 20 KB of the README was reviewed (file is about 31 KB), so later sections are not described here.
- Several entries also cover iOS, such as MobSF and Oversecured; see also [OSX and iOS Security](osx-and-ios-security.md).
