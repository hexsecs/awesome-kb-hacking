Curated list of AI security resources

## What it is
The README calls this a curated list of AI security resources, inspired by two earlier lists on adversarial machine learning and ML for cybersecurity. Entries sit in tables tagged by type (research, slides, video, web, code, other). Sections are Adversarial examples, Evasion, Poisoning, Feature selection, Misc, Code and Links, and the opening entries are mostly arXiv papers.

## Who it is for
Readers who want an academic reading list on attacking and defending machine-learning models.

## Caveats
- The section headings centre on classic adversarial-ML topics, although a few entries mention LLM agents and prompt injection; see [Prompt Injection](prompt-injection.md) for that topic.
- Mostly paper links, so expect some dead or moved URLs over time.
