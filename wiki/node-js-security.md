Curated list of tools, security incidents and other resources around Node.js security

## What it is
A curated list of Node.js security resources. The Tools part covers web framework hardening, GitHub Actions and CI/CD security, static and dynamic analysis, input validation and output encoding, secure composition, CSRF, vulnerabilities and advisories, and security hardening; a Data Sources part follows, then Security Incidents, Educational and Companies sections.

## Who it is for
JavaScript and Node.js developers and AppSec engineers looking for tooling and reference material specific to that ecosystem.

## Caveats
- Package ecosystems change fast; check that a listed tool is still maintained before adopting it.
- Generic web-security coverage is on [Web Security](web-security.md); this page is Node-specific.
- The upstream README was truncated in our capture, so later sections were not reviewed.
