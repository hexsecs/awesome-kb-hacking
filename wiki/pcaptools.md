Collection of tools developed by researchers in the Computer Science area to process network traces

## What it is
A list of tools for processing pcap files, aimed at network-traffic research. The README says the repository contains no source code or files. Sections cover Linux commands, traffic capture, traffic analysis and inspection, DNS utilities, file extraction and related projects.

## Who it is for
Network analysts, forensic investigators and researchers handling packet captures.

## Caveats
- Many entries are academic or research tools that may be unmaintained; check before depending on them.
- Capturing traffic you do not own or are not authorized to monitor can be illegal.
- The upstream README was truncated in our capture, so later sections were not reviewed.
- For rule-based network detection see [Suricata](suricata.md).
