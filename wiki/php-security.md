Libraries for generating secure random numbers, encrypting data and scanning for vulnerabilities

## What it is
This page points at the Security section of the general Awesome PHP list, not a dedicated repository. That section is a short list of PHP libraries for secure random numbers, encryption and vulnerability scanning; the excerpt we captured includes entries such as AntiXSS, Halite, PHP Encryption, PHPSecLib, PHPGGC, Roave Security Advisories, Secure Headers, SQLMap and ZAP. A neighbouring Passwords section covers libraries for working with and storing passwords.

## Who it is for
PHP developers choosing security libraries, and testers who want PHP-specific tooling such as PHPGGC.

## Caveats
- Only an excerpt of the section was captured, so the full contents were not reviewed.
- The list is mixed: defensive libraries sit beside offensive tools like SQLMap and PHPGGC; use the offensive tools only with authorization.
- Entries may be unmaintained; check each project. For Node equivalents see [Node.js Security](node-js-security.md).
