Cryptography resources and tools

## What it is
The README describes a curated list of cryptography resources and links. It is split into Theory (symmetric and asymmetric algorithms, hash functions, articles, books, courses, other lists), Tools (standalone, plugins, playgrounds) and Frameworks and Libs organised by programming language.

## Who it is for
Developers choosing crypto libraries and learners looking for courses and books on the subject.

## Caveats
- Being listed is not an audit or endorsement; check a library's maintenance and review status before using it.
- Only the first 20 KB of a roughly 46 KB README was reviewed.
- For hands-on decoding see [CyberChef](cyberchef.md); for attacks on hashes see [Password Cracking](password-cracking.md).
