This is a list of hacking research in the 3G/4G/5G cellular security space.

## What it is
The README describes a curated list of 2G to 5G cellular security research and tools, meant to preserve and organise exploits, papers, tools and learning material. It covers getting started and lab checklists, rogue base stations, base station software, SDR hardware setup, attack vectors, conference talks, papers, detection and defence, cellular IoT, private 5G, network slicing, SIM security, SS7, surveillance technology and recent CVEs.

## Who it is for
Telecom security researchers and SDR hobbyists exploring cellular protocols.

## Caveats
- The README says the material is for educational and defensive research and asks for lawful use. Radio transmission and interception are regulated in many jurisdictions, so work in shielded or licensed setups and only on equipment you own or are authorised to test.
- Large README (about 83 KB); only the first 20 KB was reviewed.
- Radio-protocol tooling is covered separately in [RFSec-ToolKit](rfsec-toolkit.md).
