A curated list of Unix binaries that can be exploited by an attacker to bypass local security restrictions

## What it is
A reference of Unix-like executables that can be abused to get around local security restrictions on misconfigured systems. The source repository README is very short and mainly points to the project at gtfobins.org and shows CI and Pages badges.

## Who it is for
Penetration testers and administrators reviewing which Unix binaries could be abused.
