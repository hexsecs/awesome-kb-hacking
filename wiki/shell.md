List of awesome command-line frameworks, toolkits, guides and gizmos to make complete use of shell

## What it is
A general command-line list, not a security list: shells, command-line productivity (including directory navigation), customization, and tools for developers. The README describes it as frameworks, toolkits, guides and gizmos for making full use of the shell, and says it was inspired by awesome-php.

## Who it is for
Anyone who lives in a terminal, including pentesters who want a faster, better configured shell.

## Caveats
- Not security-specific, so it only indirectly supports hacking work.
- Last commit is dated 2024-02-20, so newer shells and tools may be missing.
- For Unix binaries abusable for privilege escalation see [GTFOBins](gtfobins.md).
