Collection of multiple types of lists used during security assessments

## What it is
The README presents SecLists as the security tester's companion: a single repository of lists used in assessments, such as usernames, passwords, URLs, sensitive-data patterns, fuzzing payloads and web shells. It gives install options (zip, shallow or full git clone, Kali and BlackArch packages) and names its maintainers.

## Who it is for
Security testers who need ready wordlists and payloads.

## Caveats
- The README gives a shallow-clone command (`--depth 1`) as one install option.
- Contains attack payloads and web shells: use only against systems you are authorized to test.
- Related wordlist pages: [Probable Wordlists](probable-wordlists.md); payload collections: [PayloadsAllTheThings](payloadsallthethings.md).
- The README links similar projects and wordlist tools.
