OWASP Cheat Sheet Series for application security

## What it is
The official repository of the OWASP Cheat Sheet Series, which the README says offers good security practices for builders. It is a flagship OWASP project; the repository holds the Markdown sources and build, lint and container tooling, while the rendered sheets live on cheatsheetseries.owasp.org.

## Who it is for
Developers and defenders who want concise, topic-by-topic secure-coding guidance.

## Caveats
- The README states the Markdown files are working sources and should not be cited externally; reference the official website instead.
- Defensive guidance, not an offensive resource.
- This is a project repository rather than an awesome-style list.
- The README badge points to CC BY-SA 4.0 for the content.
